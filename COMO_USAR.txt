================================================================================
  CULTURA LAB.ia - Sistema de Gestão de Editais para Projetos Culturais
================================================================================

📋 COMO EXECUTAR A APLICAÇÃO:

🎯 OPÇÃO PRINCIPAL (RECOMENDADA):
   ► Clique duplo em: ABRIR_CULTURA_LAB.bat
   ✓ Instala dependências automaticamente
   ✓ Abre o navegador em http://localhost:8501

OUTRAS OPÇÕES:

Opção 2 - Execução Rápida:
├─ Arquivo: RUN.bat
├─ Uso: Clique duas vezes
└─ Nota: Mais rápido, sem mensagens extras

Opção 3 - Script VBScript:
├─ Arquivo: CULTURA_LAB.vbs
├─ Uso: Clique duas vezes
└─ Nota: Executa sem janela de terminal

Opção 4 - Criar Atalho no Desktop:
├─ Arquivo: CRIAR_ATALHO_DESKTOP.vbs
├─ Uso: Clique duplo uma vez
└─ Resultado: Cria atalho na área de trabalho

🔧 COMO USAR:

PRIMEIRA VEZ:
1. Clique duplo em: ABRIR_CULTURA_LAB.bat
2. Aguarde a mensagem "Iniciando Cultura LAB.ia..."
3. O navegador abrirá automaticamente
4. Pronto! Sistema está rodando em http://localhost:8501

PRÓXIMAS VEZES:
- Clique duplo em: ABRIR_CULTURA_LAB.bat
- Ou use o atalho no Desktop (se criado)

================================================================================
⚡ ATALHOS ÚTEIS (Para Terminal/CMD):

Navegar para a pasta:
    cd "C:\Users\Usuário\OneDrive\Documents\PROJETOS - IA"

Executar a aplicação:
    streamlit run app.py

Executar com porta customizada (se 8501 estiver em uso):
    streamlit run app.py --server.port=8502

Checar versão do Python:
    python --version

================================================================================
🆘 TROUBLESHOOTING:

❌ "Python não encontrado"
   → Instale Python 3.8+: https://www.python.org/
   → Marque "Add Python to PATH" durante instalação

❌ "Módulo não encontrado"
   → Execute: ABRIR_CULTURA_LAB.bat
   → Ele instala as dependências automaticamente

❌ "Porta 8501 já em uso"
   → Abra Terminal em PROJETOS - IA
   → Execute: streamlit run app.py --server.port=8502

❌ "Erro ao fazer upload de PDF"
   → Certifique-se que o PDF está acessível
